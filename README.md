# AI Assistance for Research

This project is an AI Assistance tool designed for research purposes. It utilizes the Groq API and the DeepSeek R1 Reasoning Model to process speech-to-text and generate intelligent responses.

## Setup Instructions

1. **Replace API Key**
   - Open `scripts/deepseek.js`.
   - Replace the API key with your own Groq API key.
   - You can obtain your API key from [Groq API Key Page](https://console.groq.com/keys).

2. **Run the Application**
   - Open `index.html` in a browser.
   - Allow access to the microphone when prompted.

## Features
- **Speech-to-Text**: Converts spoken words into text.
- **AI Reasoning**: Uses DeepSeek R1 for intelligent responses.
- **Text-to-Speech**: Converts generated responses into spoken output.

This project serves as a foundation for AI-powered research assistance and can be further expanded based on user needs.
